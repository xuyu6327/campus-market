# 校园二手交易平台 (Campus Market)

面向高校学生的二手商品交易 Web 平台，包含用户端与管理端。前后端一体，开箱即用。

> 教学/学习用途项目。隐私保护设计（联系方式加密 + 盲索引）与信用分体系是核心亮点。

## 功能特性

**用户端**
- 商品发布/浏览/搜索/筛选（分类、价格、成色、多因子热门排序）
- 收藏、浏览历史、评价（1-5 星，信用分联动）
- 预订交易流：预订 → 取消/完成，订单状态机双表联动
- 私聊（会话 + 5 秒轮询增量拉取，可平滑升级 WebSocket）
- 通知中心（订单/评价/举报/系统通知，含未读角标）
- 信用分体系（0-100）：交易加分、违规扣分，低于 10 分自动冻结账号
- 举报系统（商品/用户，处理结果联动信用分）

**管理端**
- 仪表盘：11 项运营指标
- 用户管理：搜索/封禁/启用/重置密码/调整信用分
- 商品管理：搜索/详情（解密联系方式）/强制下架/重新上架审核
- 订单、举报（警告/下架/封禁/驳回 + 恶意举报标记）、分类管理

## 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Spring Boot 2.7 · MyBatis-Plus 3.5 · MySQL 8.0 · JJWT |
| 前端 | 原生 HTML/CSS/JS（无框架），响应式 + 移动端适配 |
| 安全 | BCrypt 密码 · AES-GCM 加密（联系方式）· HMAC-SHA256 盲索引 · DFA 敏感词过滤 |
| 文档 | Knife4j（`/doc.html`） |

## 快速开始

### 环境要求

- JDK 17
- Maven 3.6+
- MySQL 8.0

### 1. 初始化数据库

```bash
mysql -uroot -p < database/campus_market_init.sql
```

### 2. 配置

`backend/src/main/resources/application.yml` 中可通过环境变量覆盖敏感配置（默认值仅供本地开发）：

| 环境变量 | 说明 | 默认值（仅本地开发用） |
|---------|------|----------------------|
| `DB_USERNAME` / `DB_PASSWORD` | 数据库账号密码 | root / 123456 |
| `JWT_SECRET` | JWT 签名密钥 | 内置测试值 |
| `AES_KEY` | 手机号 AES-GCM 加密密钥 | 内置测试值 |
| `HMAC_KEY` | 手机号盲索引 HMAC 密钥 | 内置测试值 |

> ⚠️ **生产部署必须通过环境变量更换全部密钥**，否则持有源码者即可解密全部用户联系方式。

### 3. 运行

```bash
cd backend
mvn spring-boot:run
```

- 用户端首页：http://localhost:8080/
- 管理端：http://localhost:8080/admin/index.html（管理员账号：admin / admin123，登录后请尽快修改）
- API 文档：http://localhost:8080/doc.html

### 4. 回归测试

```bash
bash scripts/api_test/run_all.sh    # 66 项接口断言测试（自动创建并清理测试数据）
```

## 安全设计

- **联系方式加密**：手机号 AES-GCM 加密存储（每次随机 IV），`phone_hash` HMAC-SHA256 盲索引用于等值查询，数据库不落明文
- **订单联系方式快照**：预订时买家选填手机/QQ/微信（至少一种），仅该订单卖家可见；买家隐私由买家自主决定
- **会话安全**：JWT 仅从 Authorization 头传递；拦截器每次请求校验用户状态（封禁即时生效）；登录失败 5 次锁定 15 分钟；用户不存在与密码错误返回统一提示（防账号枚举）
- **输入安全**：所有用户输入前端 escapeHtml 转义；标题/描述/评价/私聊消息 DFA 敏感词过滤

## 核心业务规则

- 订单状态机：商品 在售→预订中→已售出（取消恢复）；订单 待交易→已完成/买家取消/卖家取消/超时取消
- 信用分：完成交易 +2、好评 +1、买家取消 -3、差评 -2、举报核实 -10；<10 自动冻结（含下架在售商品、通知进行中订单买家），加分回升自动解冻
- 强制下架审核：被管理员下架的商品，卖家需修改后提交审核，审核通过方可重新上架
- 热门排序：近 7 天浏览×1 + 收藏×5 + 新品期(≤3天)×25
